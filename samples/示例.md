# Mist

极简的 Markdown 阅读器。窗口是**一片玻璃**，内容层只是画在上面的像素。

## 三条设计原则

- **玻璃交给系统**：`DWMWA_SYSTEMBACKDROP_TYPE` 让 DWM 合成 Acrylic / Mica，每帧零额外开销
- **圆角交给系统**：`DWMWA_WINDOW_CORNER_PREFERENCE = ROUND`，抗锯齿、阴影、贴边吸附都是免费的
- **内容只画像素**：GDI+ 画进 32 位 ARGB 位图，`SourceCopy` 提交，alpha 通道原样交回 DWM

### 为什么是 C# + WinForms 自绘

不需要 WebView，不需要 GPU 管线，也不需要运行时进程。启动一次 `ReadAllBytes`，布局一次，之后只是在同一块位图上重绘。

> 毛玻璃的关键不是模糊算法，而是**别把窗口画满**。窗口底色留 5% 透出来，背后就是 DWM 的模糊。

#### 阅读区排版

正文 15.5px、行高 1.58；标题按层级递减；代码块等宽、按宽度折行、圆角底。

```go
func main() {
    fmt.Println("hello, mist")
}
```

#### 操作

1. 拖入 `.md` 文件，或按 `Ctrl+O`
2. 滚轮滚动，空白处按住左键可拖动
3. `Ctrl` + `+` / `-` 缩放，`Ctrl+0` 复位

- 主题：纯白 / 纯黑 / 米白 / 墨蓝
- 切换：`Ctrl+1` ~ `Ctrl+4`，或点标题栏右侧的色点
